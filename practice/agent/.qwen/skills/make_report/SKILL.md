# Отчёт по TODO-задачам

1. Получи задачи из работающего приложения через `GET $TODO_API_URL/api/tasks` (по умолчанию `http://127.0.0.1:5000`).
2. Запусти скрипт из корня проекта:
   `python practice/agent/.qwen/skills/make_report/generate_report.py`
3. По умолчанию скрипт сохраняет `practice/agent/tasks_report.xlsx`. Чтобы выбрать другой путь, добавь `--output PATH`; чтобы указать другой сервер, добавь `--api-url URL`.
4. Проверь, что в книге есть листы «Сводка», «Задачи» и «Методика», число задач на сводке совпадает с источником, а статусы дедлайнов согласуются с текущей датой.

Скрипт сам получает данные, считает метрики и формирует книгу. Не пересчитывай и не переписывай статистику вручную.
