# Автоматизация входящих обращений в n8n

Три экспортируемых workflow демонстрируют один сценарий: принять обращение поддержки, определить категорию и срочность, записать его в Google Sheets и пометить срочные обращения для эскалации.

## Установка и запуск

1. Импортируйте JSON из `workflows/` в свой n8n.
2. Создайте Google Sheet с листами `Tickets` и `Escalations`. В первой строке обоих листов добавьте колонки: `createdAt`, `message`, `category`, `urgency`, `summary`, `reply`.
3. В каждой Google Sheets ноде выберите свои Google Sheets credentials, spreadsheet и лист. В экспортируемых JSON намеренно нет ключей, токенов, credential IDs и spreadsheet IDs.
4. Для вариантов 2 и 3 создайте и выберите credential OpenAI-compatible chat model, доступный вашему n8n.
5. Для проверки нажмите Execute Workflow и отправьте POST с JSON телом `{"message":"Не могу войти в аккаунт, срочно помогите"}` на показанный test webhook URL. Публикуйте workflow только после проверки; production webhook может быть доступен всем, у кого есть URL.

Правила для эскалации: срочно — если обращение сообщает о блокирующей проблеме, недоступности сервиса, потере доступа или содержит явное «срочно». Любой текст обращения считается недоверенными данными, а не инструкцией агенту.

## Сравнение

- `01_rule_based.json`: ключевые слова и правила полностью детерминированы; предсказуем, но чувствителен к перефразировкам и опечаткам.
- `02_llm_classification.json`: LLM классифицирует обращение в заданную JSON-структуру, а сохранение и эскалация остаются обычными узлами.
- `03_ai_agent.json`: агент может выбрать один или оба из двух read-only tools (справка по FAQ и правило эскалации); гибче, но результат менее детерминирован. Запись делает workflow после ответа агента, а не инструмент агента.

JSON-файлы — переносимые шаблоны: credentials и ID Google Sheet в них не сохранены. В облачном n8n проверен и опубликован только вариант 4.1; его production webhook не требует аутентификации. Варианты 4.2 и 4.3 проверены через test webhook, но не опубликованы. 4.2 вернул структурированную классификацию и записал срочное обращение в листы `Tickets` и `Escalations`. 4.3 вернул срочность `high`; в логах подтверждены вызовы FAQ и escalation tools, запись в обе таблицы и успешный ответ webhook. Не включайте ключи и токены в JSON и не публикуйте дополнительные endpoints без необходимости.
